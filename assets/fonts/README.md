# Bundled fonts

Both families are bundled so the dashboard renders without contacting a third party. Nothing here is modified; the files are converted from the upstream variable TTF to woff2 and nothing else.

| Font | License | Source |
|---|---|---|
| Manrope | SIL Open Font License 1.1 (`OFL-Manrope.txt`) | https://github.com/google/fonts/tree/main/ofl/manrope |
| JetBrains Mono | SIL Open Font License 1.1 (`OFL-JetBrainsMono.txt`) | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

The OFL permits bundling and redistribution as long as the license text travels with the fonts, which is why the two `OFL-*.txt` files sit next to them.
